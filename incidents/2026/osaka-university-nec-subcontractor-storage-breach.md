# 大阪大学・NEC — 契約外のクラウド共有・未削除の委託データ77,851人を第三者取得

## 事故の発生場所と契約上の境界

9月26日、大学の委託業務に関する個人情報を含むファイルが第三者に**ダウンロードされた事実**が確認された。10月9日、大阪大学はシステム運用委託先NECから報告を受けた。大学へ報告されていない協力会社が作業に関与し、NECは大学との契約に基づかず**個人情報ファイルをクラウドストレージへ共有**していた。作業後に**削除すべきファイルが残存**しており、それらが実際に不正取得された。[^osaka]

**本件関連の大学の教育計算機システムへの不正アクセス痕跡はNEC調査で確認されていない**。大学の本番環境侵害ではなく、委託業務で生成されたデータ複製の管理不備から発生した情報漏えいである。[^osaka]

## 母集団が重複除去済み

| 対象者 | 人数 | 主な意味 |
| --- | ---: | --- |
| 卒業生 | 59,014 | 既に卒業した人物のデータ保持も含む |
| 在学生 | 15,035 | 現役学生への成りすまし警戒 |
| 教職員 | 3,802 | 業務・所属・連絡先データ |
| **合計** | **77,851** | 大学が明示した**重複除外後の人数** |

情報は氏名、大学個人ID、大学メールアドレス、学籍番号または職員番号、所属など。個人により含まれる項目が異なる。大学は対象者ごとの内訳を後日知らせるとしており、認証パスワード自体を公表範囲へ勝手に追加しない。[^osaka]

## 再委託と保存期間を因果として認識する

| 境界 | 大学が確認した問題 | 防御に必要な監査対象 |
| --- | --- | --- |
| 再委託先の把握 | 大学に未報告の協力会社が関与 | 承認・契約関係・作業委託台帳 |
| データ共有 | 委託契約に基づかずクラウド共有 | 共有サービス、アクセス権、データの用途 |
| データ削除 | 業務終了時に消すべきファイルが残存 | 削除証跡とバックアップ・派生コピー |
| 外部取得 | 9月26日の第三者ダウンロードを確認 | ファイル単位の監査ログ、本人別データ範囲 |
| 本番業務 | 大学の計算機システムへの関連侵入は未確認 | 保守・転送・本番の各環境を分離して評価 |

**2026年9月26日の行為から大学への10月9日連絡までは13日間**。NEC側の実検知日時やその間に何をしていたかは公表から不明なので、これを「NECの検知遅延」とは断定しない。

## 対応と未確定事項

大学はNECに対し原因調査、事故収束、再発防止を要求。二次不正利用は公表時点で確認されていない。被害対象者別通知、大学と委託先の費用負担、再委託契約の見直し、クラウド共有の停止・残存データの削除証明、最終外部取得ファイル量は未確定。[^osaka]

本件は**データを最初に預かった主体の安全な本番環境だけでなく、許諾なく生成された委託先複製が事故の主因となり得る**ことを示す。認証・脆弱性対策だけでなく、業務終了後の保存期限と再委託承認の監査に接続する。
