# HISタイ法人 — 2025年12月検知、最大627人の旅券情報に流出可能性

## 時系列と初動

- **2025-12-11** 検知ソフトが不正アクセスを警告し、ファイルサーバを切断。
- **2025-12-29** 日本で取得した個人情報を確認し、PPCとJIPDECへ報告。
- **2026-02-24** 保存データ中に最大627名の旅券情報が存在すると把握、全ファイル精査を決定。
- **2026-10-07** 精査完了と対象者への順次通知を公表、19:30に一部項目を追記。[^his]

## データと確度

第三者にファイルの一部を不正に引き出された**可能性**があり、影響候補は2017、2019〜20、2024〜25年に日本からタイへ出発した一部顧客最大627人。旅券情報とアレルギー情報はデータ感度が高い。電話、住所、メール、カード情報は対象外。**627人全員のファイル外部取得が確認されたわけではない**。[^his]

## 調査長期化と予後

会計情報等の大量の無関係ファイルと形式の混在により、機械的検索が難しく、人手で照合したと説明。検知、当局報告、対象人数の把握、公表と連絡を混同しない。最終的な悪用、通知完了、海外子会社の継続監査実績は未確認。[^his]


## 対象ツアーと本人保護に必要な区別

公表PDFには個人旅行と団体旅行について異なる対象説明がある。**個人旅行**は2024年11月に日本を出発し、バンコクのプルマンホテルに宿泊してチェンマイのコムローイ祭りに参加した顧客、**団体旅行**は2017年、2019〜2020年、2024〜2025年にタイへ出発した顧客が含まれる。これらが最大627人の対象母集団の説明であり、各旅行時期がそれぞれ627人だったという意味ではない。[^his]

| 情報 | 会社の認定 | 利用者保護上の注意点 |
| --- | --- | --- |
| 旅券氏名、性別、生年月日、旅券番号、有効期限、署名欄名 | **流出した可能性** | 身分確認を装う連絡、旅行先での本人情報悪用に注意 |
| アレルギー情報 | **流出した可能性** | 変更が難しい健康関連情報として扱う |
| 電話番号、住所、メール、カード情報 | **当該保存ファイルに含まれない**と公式が追加説明 | パスワード・カード情報が実流出したと誤認しない |

対象外とされた情報は、この事故の調査対象ファイルに関する会社説明であり、同社の全保有データを意味しない。個々人に盗用が生じた事実も公式PDFには記されていない。[^his]

## 調査プロセス・通知までの実務上の課題

**検知後18日で当局報告**した一方、**2026年2月24日**に最大627名を把握してからも個人情報と会計等の無関係ファイルの混在、保存形式の違い、機械検索困難により手作業の精査が継続された。10月7日公表時点で、連絡先を特定できた対象者から個別連絡し、連絡先の特定が難しい対象者へWebで広く注意喚起した。[^his]

防御上は、保存データの分類と棚卸し、旅行終了後の保持年限、本人照会時の検索可能性、国外子会社を含むアクセスログ保存と中央監視体制の実装状況を確認すべきである。**これらを事故前に欠いていたことが証明されたわけではない**。親会社は海外セキュリティ強化と本社による監視厳格化を表明しているが、実装完了の証拠は未公表。
