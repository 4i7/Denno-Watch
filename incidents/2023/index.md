# 2023年 国内主要インシデント

2023年を、オープンウェイトLLMが一般利用者にも現実的になり始めた**比較観測開始年**として扱う。個別事故についてLLM利用を示す公開証拠がない限り、AI起因とは分類しない。

この年はRaaS、二重恐喝、VPN/境界装置、内部不正、委託先・共通認証、設定不備だけでも重大事故が十分成立していた。警察庁によれば2023年中の国内ランサムウェア被害報告は197件だった。

| 事例 | 主な失敗境界 | 即応・予後の特徴 |
| --- | --- | --- |
| [名古屋港 NUTSランサムウェア](nagoya-port-ransomware.md) | 保守VPN候補、脆弱性管理、復旧・バックアップ | 約3日物流停止。紙運用継続。事故後は港湾ガイドライン・制度改正へ波及 |
| [LINEヤフー / NAVER Cloud](line-yahoo-naver-cloud-breach.md) | 委託先PC、共通認証、組織間ネットワーク信頼 | 自社検知まで約33日。行政指導と再発防止報告が2026年まで継続 |
| [NTT西日本グループ内部不正](ntt-west-insider-data-exfiltration.md) | 特権権限、USB、委託・内部不正、調査ガバナンス | 約10年、約928万人。2023年7月の初回調査失敗が重要。2026年も改善進捗公開 |
| [セイコーグループ ランサムウェア](seiko-ransomware.md) | 未公表の初期侵入、端末/サーバ検知・認証 | 約6万件。事故後に全サーバ/PC EDR、MFA等を強化 |
| [カシオ ClassPad.net](casio-classpad-development-environment-breach.md) | 開発環境のセキュリティ設定解除、運用管理 | 国内91,921件＋海外35,049件。翌年の別ランサムウェアと異なる失敗モードで比較 |
| [JAXA VPN→Microsoft 365](jaxa-vpn-m365-breach.md) | VPN脆弱性、横展開、資格情報、SaaS | 外部機関通報が検知起点。未知マルウェア。ロケット・衛星運用系は影響外 |
| [エーザイ ランサムウェア](eisai-ransomware.md) | 未公表。国内外システム・物流依存 | 暗号化確認後に全社対策本部・外部専門家。詳細最終報告は公開範囲が限定的 |

## 読み方

- 事故件数の網羅表ではなく、2026年事例と比較価値が高い重大事例を深掘りした中核コーパス。
- 「未公表」は「対策なし」ではない。
- 事故後に追加されたEDR/MFA等を事故前能力へ遡及しない。
- 被害人数・件数は各社の母集団定義を保持し、異なる単位を安易に合算しない。
