# 概要

2024年5月26日、ニデックインスツルメンツの情報システム部門がランサムウェア攻撃を検知した。複数の業務システム内の情報が暗号化され、後続調査では同社だけでなく複数の国内グループ会社と一部海外現地法人の社内サーバー・ファイルサーバー等にも影響が及んでいたことが確認された。[^nidec-third]

攻撃者のリークサイトには本件に関連するとみられるダウンロードサイトへのリンクが掲載され、一時ダウンロード可能だったことも会社が確認した。ただし、会社は個別データについて「漏えい等が発生した、または発生したおそれ」を含めて公表しており、実際に外部取得された全件数を確定値として扱わない。[^nidec-third]

# 発生原因

会社は、攻撃者がシステム管理者アカウントのIDとパスワードを何らかの形で不正に取得し、業務システムへアクセスしたことが原因と考えられると説明した。認証情報の具体的取得経路は公表されていないため、フィッシング、インフォスティーラー、パスワード再利用等を推定しない。[^nidec-third]

# 初動・即応性

5月26日の検知当日、EDRソフトやマルウェア駆除ソフトを利用して原因マルウェアを除去し、社内対策チームを組織した。全IDのパスワード変更と侵害端末のネットワーク隔離も初期措置として行った。[^nidec-third]

翌27日にはグループ全PCで原因マルウェアが起動していないことを確認し、バックアップデータから復旧して最低限の対外業務継続体制を構築した。28日に長野県警へ通報・相談し、基幹・周辺システムの復旧を進め、6月3日に外部セキュリティ専門機関の専門調査を開始した。[^nidec-third]

したがって本件は、可視化後の初期対処と最低限の業務継続は比較的速い一方、外部フォレンジック開始は検知から約8日後、最初の対外公表は15日後だった事例として記録する。

# 情報影響

2024年7月25日の第三報では、漏えい等が発生した、またはそのおそれがある個人データとして、取引先等318,151件、オルゴール購入者・イベント参加者71,089件、従業員・元従業員・家族等13,290件を公表した。いずれも延べ件数で、本人のユニーク人数はこれより少ないと明記されている。[^nidec-third]

従業員等の対象情報には、氏名・住所等だけでなく、一部でマイナンバー、口座情報、給与・賞与・退職金情報、雇用保険被保険者番号、健康保険証番号、基礎年金番号、旅券番号など高感度情報が含まれた。[^nidec-third]

また、ニデック本体が株主優待の贈答品発送のためインスツルメンツへ委託していた当選株主の個人データも影響可能性があり、対象株主へ個別通知した。委託データが子会社事故を通じて親会社株主へ波及した例として分離して記録する。[^nidec-third]

# 事故前の公開統制との比較

ニデックの統合報告書2023は、グループ全体で情報セキュリティ管理体制を確立・厳格運用し、重要情報資産の明示、役員・職員への教育を実施すると説明していた。また、巧妙化するサイバー攻撃に対して、社外からの不正アクセス防御と、不正プログラムの動作を検知して即時に排除する仕組みの導入を進め、体制・技術の両面でグループ全体を強化したと記載していた。2022年度はサイバー攻撃等による重大事故がなかったとも報告している。[^nidec-integrated-2023]

事故当日は実際にEDR等で検知・駆除できているため、事故前統制が全面的に機能しなかったと単純評価しない。一方で、管理者認証情報の不正利用による侵入と、複数グループ会社・海外法人へのデータ影響が発生したため、**検知・駆除能力と、特権認証・ネットワーク境界・侵入後の波及制限は別の統制として評価する必要がある**。

# 事故後の再発防止

全IDのパスワード変更、不要アカウント削除、侵害端末隔離に加え、インターネット利用時は原則として社内ネットワークへ接続しないクリーンPCを使い、業務上必要な端末以外のインターネット通信を遮断する構成へ変更した。メールについても接続元IP制限を導入し、VPNで社外から社内ネットワークへ接続できるユーザーを限定した。[^nidec-third]

これらは事故後対策であり、事故前から同じ適用範囲・構成だったとは扱わない。

# 長期予後

2024年7月25日の第三報までに、漏えい等の可能性がある情報項目・件数と対象者特定、原因、初期対応、再発防止策が公開された。会社は身代金要求へ応じず、外部専門機関と連携してリークサイト監視を継続した。公表上、本件に起因する個人データの不正利用等の二次被害は同日時点で確認されていなかった。[^nidec-third]

2026年10月5日の再確認では、本件について第三報を上回る新たな被害範囲確定公表は確認できなかった。なお、ニデックグループでは2026年に別の海外子会社ランサムウェア事案が公表されているが、本件と同一事故・同一原因とは扱わない。

# 防御上の教訓

- EDRでランサムウェアを検知・駆除できても、管理者認証情報が奪われた後の横展開やデータ到達範囲は別途制限する必要がある。
- 「グループ全体の情報セキュリティ強化」という高位統制は、会社・海外拠点単位のネットワーク分離と認証カバレッジまで確認する。
- バックアップから翌日最低限の業務を再開できた点は復旧性の実証として記録できるが、機密性影響の解消とは別である。
- 子会社に委託した株主・顧客データもサプライチェーン／グループ内委託リスクとして把握する。
- 件数は延べ個人データ件数であり、ユニーク人数へ変換しない。
