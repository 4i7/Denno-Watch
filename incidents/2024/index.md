# 2024年 国内主要インシデント

2024年は、生成AI・ローカルLLMの実用利用が一般化する一方、重大事故の公開原因はランサムウェア、委託先・開発者、VPN、端末横展開、グローバルネットワーク等の既存構造が中心だった。

| 事例 | 主な失敗境界 | 即応・予後の特徴 |
| --- | --- | --- |
| [KADOKAWA / ドワンゴ](kadokawa-dwango-ransomware.md) | 集中したプライベートクラウド、ランサムウェア | ニコニコ約2か月停止、出版・経理にも波及。IRで売上84億円、営業利益64億円、特別損失36億円の影響見込み |
| [イセトー](iseto-ransomware.md) | VPN、受託データの不適切保管・削除不足 | ISO27001/27017・Pマーク保有中に事故。認証一時停止→是正後再開、経営体制再構築まで追跡 |
| [DMM Bitcoin / Ginco](dmm-bitcoin-ginco-cryptocurrency-theft.md) | 委託先開発者、セッション、正規取引の完全性 | 4,502.9 BTC窃取。DMM Bitcoinは事業終了しSBI VCトレードへ顧客資産移管 |
| [カシオ計算機](casio-ransomware.md) | フィッシング対策、海外含むグローバルネットワーク | 事故前からISMS・ゼロトラスト導入KPIを公表。経理データ遮断で決算発表延期 |
| [富士通](fujitsu-business-pc-malware.md) | 高度回避型マルウェア、業務PC横展開 | 1台起点で49台。事故前からCISO、MFA、資産可視化、ゼロトラスト・監視強化を公表 |

## この年で特に見るもの

### 「高度な対策を公表」していても侵害された事例

- カシオ: ISMS、ゼロトラスト導入率、教育・訓練を統合報告書で定量化していたが、グローバル適用差とフィッシング境界に課題。
- 富士通: 専任CISO、グローバルCISO、IT資産一元管理、侵入後検知、ゼロトラスト等を公表していたが、業務PC間で高度回避型マルウェアが拡大。
- イセトー: ISO27001/27017・Pマークを保有していたが、VPN侵入とデータ保持ルール逸脱が実事故で顕在化。

これらは「公表対策が無意味」と結論する材料ではない。事故前文書で示された**方針・認証・導入率**と、侵害資産で観測された**実効性**を別に測る。
