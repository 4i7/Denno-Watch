# 記録方法・監査

* [インシデント記録基準](reporting-standard.md) - Denno Watchで国内事例を選定・調査・更新・解釈するための標準ルール。報告・通知、データ被害、統制、OT等の条件付き横断メタデータも定義。
* [情報源の監視・鮮度・再確認基準](source-monitoring-and-freshness-standard.md) - 最終公表日と最終確認日を分離し、活動中事故から長期予後まで、情報源の再確認、差分更新、置換・撤回、長期追跡を標準化。
* [海外比較ケース記録基準](international-comparative-case-standard.md) - 海外事例を国内集計から分離し、制度差を保ったまま比較知見として利用するための標準ルール。
* [ローカルLLM時代のインシデント補助コーパス — 対象期間と評価基準](local-llm-era-corpus-scope-2026-10-05.md) - 2023年7月18日をコア期間の起点とし、AI利用の証拠状態、初動速度、事故前統制、IR・長期予後を比較するための境界を定義。
* [2023〜2025年 ローカルLLM時代補助コーパス監査 — 2026-10-05](historical-corpus-audit-2023-2025-2026-10-05.md) - 第1次歴史監査。国内16件を再確認し、事故前PDF、初動、復旧、規制・財務・長期予後、AI関与の確度を統一基準で整理。
* [Denno Watch 全収録事例再調査 — 2026-10-05](full-corpus-reaudit-2026-10-05.md) - 2023〜2025年を23件へ拡張し、2026年42件の前日一次監査に10月5日の差分検索を重ね、国内65件すべてを現在の記録基準で再確認。
* [2026年 重大インシデント事例集監査 — 2026-10-04](corpus-audit-2026-10-04.md) - 2026年42件を一次情報と再照合し、OKF適合性と事例横断の防御知見を確認した基準監査。
