# 読み方

資料を次の4種類に分離する。

1. **事故前の統制資料** — 統合報告書、サステナビリティ報告書、情報セキュリティ方針、認証資料等。
2. **事故そのものの調査資料** — 初報、続報、フォレンジック結果、最終報告。
3. **株主・財務資料** — 適時開示、決算、株主総会、有価証券報告、内部統制報告等。
4. **規制・第三者評価・下流資料** — 行政指導、報告徴求、認証停止・再開、委託元や顧客組織の通知等。

事故前資料に書かれた統制は、文書上の方針・施策・認証の存在を示す。事故対象資産への実装、例外の不存在、運用品質、有効性までは証明しない。事故後の再発防止策を事故前統制へ遡及させない。

# 比較を抑制するケース

HOYA、セイコー等にも統合報告書や企業セキュリティ資料は存在するが、事故の具体的失敗面へ直接対応する事故前記述を十分に確認できない場合、資料の存在だけで「対策を明記していたのに破られた」と評価しない。

# 証拠台帳の記録単位

各資料について、発行主体、発行日・対象年度、事故前／事故後の区分、URLまたは固定版、宣言された統制、事故の失敗面への適用性、差し替え・削除の有無を保持する。再発防止策は `announced / implemented / tested / independently_assessed / operationally_observed` を分ける。

比較対象は「セキュリティ資料の有無」ではなく、**宣言・適用範囲・例外・運用・検知・復旧・規制・財務の証拠**である。
