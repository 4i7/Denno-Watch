# 現在強い領域

## 1. 国内の公開事実

42件の2026年国内重大インシデントについて、一次情報を中心に時系列、影響、技術事項、対応、復旧、予後、不明点を記録している。

## 2. 大規模データ・本人確認情報

タイムズカー、Helpfeel / Gyazo、PeakManager、アフラック等から、件数だけでなくデータ感度、保持期間、本人保護の長期性を比較できる。

## 3. ランサムウェアと復旧

日本テレネット、マルタケ、REXT、CEC、京王等から、暗号化、持ち出し、業務停止、クリーン再構築、仮環境、攻撃者サイト掲載の違いを比較できる。

## 4. 第三者・SaaS・共有基盤

ApplyNow、両毛システムズ、日本テレネット、KDDI、メディア4uと海外比較ケースから、一社の侵害が複数組織へ波及する条件を辿れる。

## 5. AI時代の脅威経済性

AI、ローカルモデル、外部計算資源、24時間365日自動化が攻撃側の探索・作業量・一貫性をどう変え得るかを、観測事実と推論を分離して扱っている。

# 新たに補完した不足領域

今回、既存資料からさらに辿った結果、次を独立資料化した。

1. **ライフサイクルと復旧判定** — サービス再開だけを「完了」としない。
2. **第三者・認証・集中リスク** — 委託先評価票では見えない到達範囲・データ集中・復旧依存を扱う。
3. **長期予後** — 本人保護、規制、契約、訴訟、保険、信用、技術負債を追う。
4. **対応指標と経営判断トリガー** — 最初の60分、全面停止／部分隔離、復旧開始・完了条件を扱う。
5. **海外比較ケース** — 国内ではまだ観測期間が短い数年単位の尾部を補完する。

# 今後も継続して深掘りする価値が高い領域

以下は現時点で完全な独立資料にするほど国内公開根拠が揃っていないか、制度調査を追加した方がよい領域である。欠落として明示し、将来調査の優先順位にする。

## 本人確認・身元情報の二次悪用

必要な追加観測:

- 本人確認書類流出後の不正契約、口座開設、融資、携帯契約等の公的統計・事例。
- 事業者が本人保護として実施した信用監視、再本人確認、書類再発行支援等。
- 「二次悪用未観測」をどの期間・情報源で確認したか。

タイムズカー等の予後更新と接続する。

## サイバー保険

必要な追加観測:

- 日本企業の事故で公表された保険金、免責、支払上限、求償。
- MFA、バックアップ、EDR等が保険条件へどう反映されるか。
- 大規模事故後の更新条件・保険料変化。

海外MOVEit等では長期費用と保険枠消尽が観測できるが、日本へ直接換算しない。

## 事故後の顧客・売上・解約影響

公開情報では原因をサイバー事故だけに帰属しにくいため、無理な推計を避けている。決算資料等で事故影響が明示された場合のみ独立分析へ昇格する。

## 人員・組織疲弊

長期対応による開発遅延、担当者疲弊、採用・離職、外部専門家依存は重要だが、公開定量情報が少ない。一次資料が得られる事例を継続探索する。

## OT・安全系

現在の国内2026事例集は情報システム・Web・SaaS・業務基盤が中心で、物理安全へ直結するOT侵害の観測例が相対的に少ない。国内外の公開ケースを別途調査する価値が高い。

## 攻撃後の再発率・是正効果

同一企業で数年後に同種事故が再発したか、導入した対策が有効だったかは、単年事例集では判断しにくい。2027年以降も同一組織を追跡し、是正策の「発表」ではなく結果を評価する。

# 追加調査の優先順位

優先度は、情報量ではなく防御判断への価値で決める。

| 優先度 | 条件 |
| --- | --- |
| P0 | 人命・重要供給・金融・通信、100万件級高感度データ、複数組織へ波及、重大な新規原因確定 |
| P1 | 原因・件数・データ種別・復旧状態の重要更新、本人通知・規制・攻撃者公開、重大な是正策 |

# ナレッジベースとしての最終到達点

Denno Watchで一つの重大事故を読むと、最終的には次を答えられる状態を目標とする。

1. 何が起きたか。
2. いつ始まり、いつ検知されたか。
3. 何が入口だったか、または何が不明か。
4. どの境界を越えて被害が拡大したか。
5. 何が盗まれ、壊され、止まったか。
6. 誰に下流影響が出たか。
7. 何が被害を増幅し、何が抑制したか。
8. どの速度で封じ込め・復旧したか。
9. 技術復旧と業務復旧はいつだったか。
10. 影響人数・データ種別はいつ確定したか。
11. 本人・顧客・当局への対応はどう進んだか。
12. 再発防止策は発表だけでなく実装・検証されたか。
13. 数か月〜数年後に何が残ったか。
14. 同じ構造を持つ国内外の事故は何か。
15. 自組織なら何を事前に直し、何を事故時に測るべきか。

この15問を横断して答えられることを、単なるニュース保存ではなく**再利用可能な防御知識基盤**としての完成条件とする。
